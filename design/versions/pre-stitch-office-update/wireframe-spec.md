# Wireframe Office W02 — Power9 Office Routine

Đặc tả mới thay bộ wireframe Family Routine. Khung 360×800; kiểm tra 412; lề 16, body 16, nhãn ≥14, vùng chạm ≥48. Đen trắng, không dùng ảnh/màu để che lỗi bố cục.

| Màn | Thứ tự từ trên xuống |
| --- | --- |
| S01 | Tên app → ngày làm việc → vài việc đã chọn theo giờ và nguyên tắc → hoàn thành/hoàn tác → ba tab |
| S02 | Back → Bữa trưa → card H04 → card H05 → ghi nhận riêng |
| S03 | Back → H03 Downshift → 3 phút → điều khiển phiên → hướng dẫn → xác nhận rời |
| S04 | Back → Kết nối → H06 ghi rõ điều chỉnh → H07 ghi rõ điều chỉnh → H09 → chọn hành động |
| S05 | Chín thói quen → tìm kiếm có nhãn → lọc thời lượng → đủ 9 card có tên gốc → ba tab |
| S06 | Back → nguyên tắc gốc → ý nghĩa → áp dụng/điều chỉnh → nguồn → hành động + thời lượng → thêm/đổi lịch |
| S07 | Back → hành động → ngày làm việc → giờ → nhắc tùy chọn → giờ yên lặng → lưu/hủy |
| S08 | Tiến độ cá nhân → số việc hoàn thành/tự chọn → nhóm theo nguyên tắc → lịch sử → ba tab |
