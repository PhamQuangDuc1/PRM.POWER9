# Quy ước ngôn ngữ và thuật ngữ

## Ngôn ngữ tài liệu

Dùng tiếng Việt có dấu cho giải thích, hướng dẫn thao tác, bảng nhận xét và prompt mới. Nội dung ứng dụng cũng dùng tiếng Việt có dấu. Tên sản phẩm Power9 Family Routine, công cụ và tên file không đổi.

Giữ mã S01–S08, F01–F03, UX01–UX06, W00, V00, I01–I03 và tên token để truy vết. Giữ tên mục giao diện Figma khi cần tìm đúng thao tác.

## Thuật ngữ thống nhất

| Thuật ngữ gốc | Cách giải thích tiếng Việt |
| --- | --- |
| Persona | Chân dung người dùng |
| Problem statement | Phát biểu vấn đề |
| UX criterion / success criterion | Tiêu chí thành công UX |
| Information architecture / IA | Kiến trúc thông tin, cấu trúc điều hướng |
| User flow | Luồng sử dụng |
| Happy path | Nhánh thành công chính |
| Alternate path | Nhánh thay thế |
| Error / recovery | Lỗi / phục hồi |
| Wireframe / low-fi | Bố cục phác thảo ít chi tiết |
| Final UI | Giao diện hoàn thiện |
| Design system | Hệ thống thiết kế |
| Design token | Giá trị thiết kế dùng chung |
| Component | Thành phần tái sử dụng |
| Instance | Phiên bản sử dụng của component, còn liên kết với bản gốc |
| Variant | Biến thể |
| State | Trạng thái |
| Default / populated | Mặc định / có dữ liệu |
| Loading / empty / error | Đang tải / rỗng / lỗi |
| Overlay | Lớp phủ, thường dùng cho hộp thoại |
| Prototype | Bản mẫu tương tác |
| Handoff | Tài liệu bàn giao triển khai |
| Prompt | Chỉ dẫn gửi cho AI |
| Critique / finding | Phản biện / vấn đề phát hiện |
| Iteration | Vòng cải tiến |
| Accept / modify / reject | Chấp nhận / điều chỉnh / từ chối |
| Before / after | Trước / sau chỉnh sửa |
| Evidence | Bằng chứng |
| Auto Layout | Bố cục tự động; giữ tên tính năng để thao tác Figma |
| Variables / styles | Biến / kiểu dùng chung trong Figma |
| CTA | Hành động hoặc nút chính |

## Trạng thái hồ sơ

Dùng: CHƯA CHẠY, SẴN SÀNG CHẠY, ĐÃ CÓ ĐẦU RA MỘT PHẦN, ĐÃ REVIEW, CHƯA KIỂM TRA, ĐÃ KIỂM TRA. Chỉ đánh hoàn tất khi có artifact và kết quả kiểm tra tương ứng.

## Nguồn phải giữ nguyên

Không dịch đè nội dung nguồn sau đây vì cần đối chiếu đúng phiên bản đã chuẩn bị hoặc dùng để đánh giá:

- ai/prompts/P00-stitch-initial.md: prompt ban đầu có thể đã dùng cho V00; nguyên văn thực gửi chưa xác minh đầy đủ.
- design/versions/DESIGN-V00-green.md: bản brief xanh lá nguồn.
- ai/critiques/C00-review-criteria.md: tiêu chí tiếng Anh dùng cho review V00.
- ai/critiques/C00-response-original.md: báo cáo C00 tiếng Anh trước khi Việt hóa.

Các file nguồn vẫn có thể chứa tiếng Anh. Bản hiện hành DESIGN.md và C00-response.md là tiếng Việt. Không gọi bản dịch là một lần chạy AI khác hoặc prompt nguyên văn của lần trước.

Ảnh nguồn giữ nguyên chữ xuất hiện trong công cụ. Các trích dẫn lỗi như “Hom Nay” phải giữ đúng để chứng minh lỗi, không tự sửa chữ trong ảnh.
