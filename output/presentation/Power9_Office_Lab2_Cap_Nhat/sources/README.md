# Nguồn bộ trình bày Office

Nguồn HTTPS ở chân mỗi slide trỏ tới tài liệu chính thức, Figma hoặc commit GitHub đã push. Các bản sao trong thư mục này dùng để tra cứu khi mất mạng.

Người dùng xác nhận ngày 27/10/2026 đã gửi nguyên văn 100% các prompt Office do trợ lý cung cấp trên Stitch mới. Toàn văn prompt UI01 nằm trong notes slide 05 và ai/prompts/OFFICE-UI01-from-final-wireframe.md.

Ảnh Stitch là đầu ra đã xuất. Cặp font S07 trước/sau là kiểm chứng Chrome cục bộ. Ảnh Figma là ảnh node đã lưu, xem evidence-provenance.json. UI-OVERVIEW và RESPONSIVE-412 là mốc trước cập nhật accordion; ACCORDION.png thể hiện phần bổ sung.

Số liệu kiểm tra thiết kế không thay cho user test. Figma MCP hết hạn mức Starter trong lượt này, chưa có kiểm tra trực tiếp mới.
